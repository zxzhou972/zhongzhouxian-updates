# 中轴线 · 万代库存监控

独立 Windows EXE 客户端的正式更新下载仓库。

首次使用：从 Releases 下载完整 ZIP，解压后双击“万代库存监控.exe”。

v1.5.0 起，打开程序左侧“版本更新”，即可检查、下载并安装新版。安装前暂停所有自动任务。旧版 1.3 / 1.4 / 1.4.1 需要完整安装本版一次。

只有主设备签发并正式发布的版本才会被接受。朋友端无需 GitHub 账号，只能接收更新。

商品记录、Bark 设置和平台冷却记录保留。重启后重新登录个人 Token。

本工具只读查询库存、商品信息和本人待支付订单，不创建订单、不付款。程序包不包含个人 Token、Bark 设备 Key、个人记录或发布私钥。
